# The mark

Three things the product does, in one drawing.

The outer brackets are a **scan reticle** — what the phone frames before it
reads a room. Inside it sits a **sheet with a gable**: the bid and the building
it is for are the same object here, because in this app they are produced in one
act rather than one after the other. The two ink rules are line items; the amber
rule under them is the **total**.

Colours are the ones the rest of the product already uses: ink `#14181B`, and
the amber `#B8590A` that means *measured* on the plan, on the field card, and in
the app.

| File | Where it is used |
|---|---|
| `scantobid-mark.svg` | The app icon: white on ink, full bleed, no rounded corners — iOS supplies the mask. |
| `scantobid-mark-light.svg` | The same mark in ink on nothing, for light ground. |
| `scantobid-wordmark.svg` | The horizontal lockup, mark then name, `ToBid` in amber. |
| `scantobid-icon-*.png` | Rasterised from the mark. 1024 is the App Store size. |
| `scantobid-wordmark.png` | The lockup at 2×, transparent, for anywhere that will not take an SVG. |
| `rendered-from.json` | What each PNG was drawn from. Written by the generator; do not edit. |

**Do not hand-edit the PNGs.** They are rendered from the SVGs:

```bash
npm run logo          # redraw every PNG from the SVGs beside it
npm run check-logo    # fail if a PNG no longer matches the SVG it came from
```

`npm run check-logo` runs inside `npm run verify`, so a mark that is changed and
not re-rasterised fails the build rather than shipping half-updated.

## Where else the same drawing lives

The mark is drawn in four places for four different reasons, and three of them
are generated or checked so they cannot drift apart:

| Where | How it stays in step |
|---|---|
| `web/src/Mark.tsx` | **The source.** Every screen in the app draws it from here. |
| `ios/Trueline/Assets.xcassets` | Generated by `core/tools/gen-art.mjs`, which reads the geometry back out of `Mark.tsx` and fails if it has moved. |
| `assets/logo/*.svg` | Hand-kept, rasterised by `core/tools/gen-logo.mjs`. |
| `web/public/icon.svg`, `site/src/favicon.svg`, the site header | Redrawn deliberately for 16–32 px: the two line items inside the sheet are dropped and the strokes are heavier, because at that size they close up into a grey block. |

The icon the app actually ships is
`ios/Trueline/Assets.xcassets/AppIcon.appiconset/icon-1024.png`, which has no
alpha channel — the App Store requires that, and the generator guarantees it by
shooting the mark over an opaque page.
